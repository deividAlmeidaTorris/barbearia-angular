# 💈 Barbearia Prime

Projeto de site institucional para barbearia, desenvolvido com **Angular 18**, com layout moderno, responsivo e foco em boas práticas de front-end.

## 🚀 Tecnologias utilizadas
- Angular 18
- TypeScript
- HTML5
- CSS3
- Angular Router
- Git & GitHub

## 📱 Funcionalidades
- Navbar responsiva (menu mobile)
- Página Home com banner
- Página Sobre
- Página de Contato com formulário
- Footer fixo
- Layout responsivo para celular, tablet e desktop



## 🛠️ Como executar o projeto
```bash
npm install
ng serve
